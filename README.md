# Terbium VM
a stack-based bytecode interpreter written in rust

---

## Install

Requirements:
- `rust`
- `cargo make`

```bash
git clone https://github.com/ayxan20145-prog/TVM.git
cd TVM
cargo make install
```

## Uninstall
```bash
cargo make uninstall
```

## Run a program
```bash
terb <FILE>
```
