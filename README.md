# Terbium
a stack-based bytecode interpreter written in rust

---

## Install
```bash
git clone https://github.com/ayxan20145-prog/Terbium.git
cd Terbium
chmod +x scripts/install.sh
./scripts/install.sh
```

## Uninstall
```bash
chmod +x scripts/uninstall.sh
./scripts/uninstall.sh
```

## Run a program
```bash
terb <FILE>
```
